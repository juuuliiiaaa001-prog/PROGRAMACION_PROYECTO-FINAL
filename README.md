# Sistema de gestion de restaurante

## contenido:

* **Lenguaje:** Python
* **Bibliotecas estandar:**
     *`json`(Almacenamiento de datos)
     *`datatime`(Registro de fecha/hora de pedidos)
     *`os`(limpieza de consola)

* **`Interfaz.py:`** mesas disponibles para hacer reservaciones.
* **`Menu.py:`** define la clase, los items y los precios que maneja el restaurante.
* **`Reservaciones.py:`** gestiona el control de mesas y registro de clientes.
* **`pedidos_ordenes.py:`** maneja y gestiona el historial de ordenes.

### Funciones:
* **Persistencia de datos**
* **Gestion de prioridad (reservaciones)**
* **Validacion de entradas**
* **Eleccion de items**
